# Sultan Voic - تطبيق الغرف الصوتية الملكية (30 مقعداً) 👑

تطبيق غرف صوتية إمبراطوري كامل مكتوب بإطار العمل **Flutter** و **LiveKit WebRTC** و **Supabase**:

## 🌟 الميزات المضمنة في هذا المشروع:
1. **غرفة 30 مقعداً ملكية**: مدعومة بتقنية LiveKit WebRTC عالية النقاوة.
2. **وضع السينما (Cinema Mode)**: 10 مايكات متراصة أسفل شاشة عرض الفيديو مع نظام الـ CP بالقلب النابض الفخم.
3. **ميكسر الأغاني والموسيقى (Audio Mixer)**: بث ملفات الصوت من جهاز العضو مباشرة مع استمرار البث النقي حتى لو تم كتم المايكروفون.
4. **حزمة باكيج الـ SVIP 9 بالكامل**:
   - SVIP 4-6: سيارات فخمة تفحط.
   - SVIP 7-8: ذئب فضي مشتعل يعوي.
   - SVIP 9: زئير أسد ذهبي ضخم مع الصقر الأسود وألسنة اللهب.
   - دعم كامل لـ Lottie و SVGAPlayer-Android بـ 60 FPS.
5. **لوحة الصلاحيات التفكيكية**: للسوبر أدمن (المعرف 1) فقط لمنح وسحب الصلاحيات للمشرفين.
6. **حزمة الألعاب الثلاثية الكاملة**:
   - تايغر سلوت (Fortune Tiger 🐯)
   - كنوز التنين (Dragon Treasure 🐉)
   - جريدي بوكس (Greedy Box 🎁)
   - بالإضافة إلى ألعاب الروليت وعجلة الحظ وسلوت 777.

## 🚀 كيفية رفع المشروع إلى GitHub وطبخ الـ APK تلقائياً:

### الخطوة 1: فك ضغط هذا الملف على جهازك
افتح مجلد المشروع في الـ Terminal أو VS Code.

### الخطوة 2: إنشاء مستودع جديد على GitHub
1. اذهب إلى https://github.com/new
2. أنشئ مستودعاً جديداً باسم: `sultan-voic-app`

### الخطوة 3: رفع الكود بـ 3 أوامر فقط
```bash
git init
git add .
git commit -m "feat: Sultan Voic Master Codebase with LiveKit and APK workflow"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/sultan-voic-app.git
git push -u origin main
```

### الخطوة 4: تحميل الـ APK المطبوع
- بمجرد عمل `git push`، سيبدأ ملف الأتمتة `.github/workflows/build_apk.yml` فوراً بطبخ الـ APK!
- ادخل على تبويب **Actions** في صفحة المستودع على GitHub.
- انتظر 3-4 دقائق، وستجد ملف **sultan-voic-release-apk** جاهزاً للتحميل المباشر والتثبيت على هاتفك!
